# Capacity Connect

Build a REAL, FULL-STACK, MULTI-USER web application called:

CAPACITY CONNECT

Tagline:
"Build Skills. Build Capacity. Build the Future."

This is not a static mockup, fake prototype, or demo-only application.

I need a genuinely working web application where real users can register, log in, create content, access content, submit work, manage data, and interact with each other through a real database.

The development team consists of complete beginners with no programming experience, so you must implement the application for us and keep the architecture understandable and maintainable.

The complete specification is in the attached file "Build a REAL, FULL-STACK, MULTI-USER web (pasted).md" — read it in full and implement every requirement it contains, including the three roles (TRAINEE, TRAINER, ADMIN), real authentication with role-based authorization, trainer approval workflow, the trainee portal, trainer course/content management, admin administration, and a real database with no hardcoded demo data.
